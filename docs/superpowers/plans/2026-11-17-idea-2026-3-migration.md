# IntelliJ IDEA 2026.3 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** 将 MarkNote 迁移到 IntelliJ IDEA 2026.3 / Platform 263，并让构建、测试和插件打包使用可复现的 Java 25、Kotlin 2.x 和 Gradle 9.x 工具链。

**Architecture:** 只迁移构建与测试边界，保留现有 Note、锚点、服务、编辑器展示和持久化实现。使用 IntelliJ Platform Gradle Plugin 2.20.1 的新 DSL，以 `intellijIdea("2026.3")` 和 Java bundled plugin 提供 IDE API；测试同时保留 Platform fixture 和 JUnit 5 纯逻辑测试。

**Tech Stack:** Gradle 9.9.1 Wrapper、IntelliJ Platform Gradle Plugin 2.20.1、IntelliJ IDEA 2026.3、Java 25、Kotlin 2.x、JUnit 5。

**Spec:** `docs/superpowers/specs/2026-11-17-idea-2026-3-migration-design.md`

## Global Constraints

- IntelliJ Platform target: `2026.3`, branch `263`。
- Plugin compatibility: `since-build = 263`, without `until-build` so future platform versions remain installable。
- Gradle plugin ID: `org.jetbrains.intellij.platform`。
- Gradle version: 9.x, pinned by Wrapper。
- Java toolchain: 25。
- Toolchain resolution: use the Foojay resolver convention plugin so Gradle can provision Java 25 when the local JDK is missing。
- Kotlin: 2.x, with IntelliJ bundled stdlib preferred。
- Preserve plugin ID `soulx.MarkNote` and `CodeReadingNoteLite.xml` storage isolation。
- Do not change domain behavior unless required by a 2026.3 API compile error。

## Review Focus

- Build DSL migration must remove every old `intellij {}` and `org.jetbrains.intellij` reference。
- Test framework wiring must compile both JUnit 5 unit tests and `BasePlatformTestCase` tests。
- Java/Kotlin target must not silently fall back to Java 17。
- Patched plugin XML must advertise build 263 and preserve the independent plugin ID。
- Existing legacy XML isolation must remain unchanged。
